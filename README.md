## Introduction
This project deploys a Full stack todo application into a Kubernetes cluster on Minikube. This todo application is forked from [Ayush-Kanduri/FullStack-Todo-List-Application](https://github.com/Ayush-Kanduri/FullStack-Todo-List-Application), this project just adds dockerizes the project and deploys in a Kubernetes cluster.
